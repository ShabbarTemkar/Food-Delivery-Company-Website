FastBite is a responsive, single-page food delivery platform allowing users to browse restaurants, inspect full menus via interactive modal dialogs, and manage an active cart using a slide-out drawer with real-time subtotal calculations. Built with semantic HTML5, mobile-first CSS3, and vanilla ES6+ JavaScript.

---

## 🌟 Key Features

- **Sticky Navigation & Live Cart Badge:** Persistent header with smooth anchor navigation and an interactive badge counter showing real-time item counts.
- **Promotional Hero Banner:** High-conversion promotional section highlighting active discount voucher codes (`FASTBITE20`).
- **Responsive Restaurant Grid:** Fluid 1, 2, and 3-column CSS Grid layout featuring hover card elevations.
- **Interactive Menu Modal:** Accessible dialog overlay displaying itemized menus with pricing and "Add to Cart" triggers.
- **Slide-In Off-Canvas Cart Drawer:** Smooth slide-out panel allowing diners to view line items, remove items, and track live order subtotals.
- **Mobile-First Responsive Architecture:** Optimized for all screen sizes from 320px mobile viewports to large desktop monitors.
